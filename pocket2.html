Rules

Elevation (Stand)

  • Count completed tasks, across every goal
  • Every task counts the same — no bonus for "more"
  • Skipped tasks don't count either way — excluded, not penalized
  • Tasks scheduled for specific weekdays only count on those days
  • Divide by the total number of applicable tasks → your %, capped 0–100

Each goal's battery

  • Its own completed tasks ÷ its own applicable tasks that day

Peaks (stacked bar)

  • One bar per point (a day at 1W/1M, a week or month bucket at wider ranges) — a point with nothing logged shows no bar at all
  • Each goal gets a segment stacked on the bar, bottom to top, in goal order
  • Segment height = that goal's own completion % — no streaks, no multipliers, no scaling trick
  • The chart's height auto-scales to whichever point's stack is tallest on screen
  • Goal order only sets stacking order (which segment sits at the bottom) — it never changes any score

Emoji goals (like Mood)

  • Never add to the elevation score — they get their own range on Peaks, not a share of anyone else's
  • A goal's own penalty flag (if it has one) only affects that goal's own %

Notes & quiet messages

  • The daily note never affects any score — it's just for you
  • The quiet message under elevation only appears on genuinely low days

Task gesture

  • Tap a task to cycle: empty → ✓ done → – skipped → empty
